Detailed Description

Read a packet capture file containing UDP packets.

A simple file reader that handles only UDP (and multicast) packets. For more power, see tcpdump and/or the libpcap open source project.

Capture files are read through libpcap, so classic pcap in either endianness and at either timestamp resolution, and pcapng, are all accepted without the caller having to know which it has. Building with -DQUICKFAST_USE_LIBPCAP=OFF leaves open() reporting that capture support was not compiled in.
