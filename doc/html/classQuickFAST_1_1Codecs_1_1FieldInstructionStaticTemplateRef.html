decodeSignedInteger() specialized for int64.

Scans for the stop bit in the source's own buffer when it can offer the whole value – at most (64+6)/7 = 10 bytes – and falls back to the generic byte-at-a-time loop when it cannot. Behaviour, including the errors reported, is identical either way.

Parameters
[in]sourcesupplies the data
contextin which the decoding occurs.
[out]valuereturns the result
[in]nameof this field to be used in error messages
[in]oversizeignores one bit of overflow to cope with out-of-range deltas (see section 6.3.7.1 of the Fast Specification v1x1)
[in]ignoreOverflowignores overflows completely to cope with funky ARCA encoding.

References QuickFAST::Codecs::DataSource::getByte(), QuickFAST::Codecs::DataSource::hasContiguous(), QuickFAST::Codecs::Context::reportError(), QuickFAST::Codecs::Context::reportFatal(), and QuickFAST::Codecs::DataSource::skipContiguous().
