Detailed Description

spdlog file sink: size + scheduled rotation, gzip, retention, Asio timer.

Shares an application asio::io_context (e.g. AsioService::ioService()) for hard time-based rotation without requiring log traffic. Does not install its own signal_set; call request_shutdown() from the app's signal handler.

Example
QuickFAST::Communication::AsioService service;
auto sink = std::make_shared<QuickFAST::Common::managed_file_sink_mt>(
service.ioService(),
QuickFAST::Common::ManagedFileSinkConfigBuilder()
.base_path("/var/log/quickfast/feed.log")
.max_file_bytes(64ull << 20)
.max_managed_bytes(1ull << 30)
.build());
auto logger = std::make_shared<spdlog::logger>("feed", sink);
QuickFAST::Common::SpdlogLogger adapter(logger);
// ... run the decoder, sharing service.ioService() ...
sink->request_shutdown(); // from the app's signal handler or at exit

First instant at or after from at which hour:minute occurs in zone.

DST-safe: a local time inside a DST gap resolves to the instant the offset changes, and an ambiguous local time to the later of its two instants. Never throws for a valid zone.

Example
const auto next = managed_file_sink_mt::next_rotation_after(
std::chrono::locate_zone("America/Santiago"),
std::chrono::system_clock::now(), 0, 0);

Cancel timer, stop compression workers, flush and close the active file.

Blocks until any in-flight rotation timer handler has finished, so the sink may be destroyed afterwards even while the shared io_context keeps running. Idempotent.
