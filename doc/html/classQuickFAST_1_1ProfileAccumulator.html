Detailed Description

Accumulate profiler statistics.

A ProfileAccumulater is statically created for each Profile Point. The ProfileInstances created to do the actual timing store their results into the corresponding ProfileAccumulator. These accumulators link themselves together in a list starting at root_. Walking this list lets you find all profile points in the system. The static write(...) method writes a tab-delimited file of the statistics. Hint: try importing this file into a spreadsheet for analysis.
