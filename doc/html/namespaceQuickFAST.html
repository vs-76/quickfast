Detailed Description

General utility/overhead classes used throughout the rest of the system are in the QuickFAST namespace.

Source files for elements in this namespace are in the src/Common directory. They include QuickFAST::Decimal, the exceptions QuickFAST throws (QuickFAST::EncodingError, QuickFAST::OverflowError, QuickFAST::TemplateDefinitionError, QuickFAST::UsageError and their siblings), and the logging support in QuickFAST::Common.

This page was generated from comments in src/Common/QuickFASTPch.h
