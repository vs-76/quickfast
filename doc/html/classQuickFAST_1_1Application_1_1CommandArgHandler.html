virtual int QuickFAST::Application::CommandArgHandler::parseSingleArg ( int argc,
char * argv[] )
pure virtual

Parse a single argument from the command line.

Each call should consume one logical argument. You will be called again to consume subsequent arguments. For example if your implementation accepts arguments -f [file] and -v, and argc is -f output -x -v you should interpret [-f output] and return 2. Do NOT go looking for the -v.

Parameters
argcthe count of remaining, unparsed arguments
argvthe remaining, unparsed arguments from the command line
Returns
the number of arguments consumed. 0 means argv[0] was not recognized; ARGUMENT_VALUE_ERROR means it was recognized but its value was not, and has already been reported.

◆ ARGUMENT_VALUE_ERROR

const int QuickFAST::Application::CommandArgHandler::ARGUMENT_VALUE_ERROR = -1
static

Recognized the option, but rejected its value.

Distinct from returning 0, which means the option itself is unknown. A handler that conflates the two makes the parser announce that a perfectly valid option does not exist. The handler is expected to have reported the specific problem before returning this.
