Detailed Description

Classes for managing FAST application data: messages and fields.

This namespace focuses on using the application data. It has no knowledge of the encoding/decoding process. In particular nothing in this namespace should know anything about the QuickFAST::Codecs namespace.

Application data is sent to and from QuickFAST via QuickFAST::Messages::Message objects. A Message is a collection of QuickFAST::Messages::Field objects. Each field within the message is identified by a QuickFAST::Messages::FieldIdentity.

Source files for elements in this namespace are in src/Messages directory.
