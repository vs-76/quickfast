◆ base_path

std::filesystem::path QuickFAST::Common::ManagedFileSinkConfig::base_path

Path of the active log file; rotated names derive from it.

The parent directory is created if it does not exist. The stem and extension are reused for rotated files, so app.log rotates to names of the form app-20260830-120000.log.gz.

◆ max_file_bytes

std::size_t QuickFAST::Common::ManagedFileSinkConfig::max_file_bytes = 8ull << 20

Rotate the active file once it exceeds this size.

Must not exceed max_managed_bytes under RetentionMode::ManagedBytes: retention never evicts the active file, so a larger value would let the active file alone overrun the whole budget with nothing to reclaim.
