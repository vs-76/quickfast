Detailed Description

Classes involved in passing data to/from the Decoder/Encoder from/to the outside world.

Classes in this namespace address the issues involved in:

  • reading data from communication sockets
  • reading data from data files
  • handling any framing or other non-FAST information in the incoming data.
  • delivering the incoming data to a decoder
  • accepting outgoing data from an encoder
  • adding any framing or other non-FAST information to the outgoing data.
  • writing outgoing data to communication sockets
  • writing outgoing data to files

Source files for elements in this namespace are in src/Communication directory.

Resolve host and service to TCP endpoints (AF_UNSPEC).

When QuickFAST is built with QUICKFAST_HAVE_CARES, uses c-ares (hosts file + DNS; no glibc NSS). Otherwise uses Asio's ip::tcp::resolver (getaddrinfo).

Numeric host strings skip name lookup. Service may be a port number or a TCP service name (resolved by the active backend).

Parameters
ioContextAsio context (used by the Asio backend).
hostHostname or numeric address string.
servicePort number or TCP service name.
ecSet on failure; cleared on success.
Returns
Endpoints suitable for tcp::socket::connect; empty on error.
