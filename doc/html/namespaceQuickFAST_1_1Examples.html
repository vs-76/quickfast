Detailed Description

Sample applications and reusable sample components.

Example programs to demonstrate and test QuickFAST.

Nothing in the QuickFAST libraries depends on this namespace; it exists to be read and copied. QuickFAST::Examples::JsonMessageConsumer and QuickFAST::Examples::MessageInterpreter are the message consumers the bundled applications use, and are usable as-is.

Source files for elements in this namespace are in the src/Examples directory.
