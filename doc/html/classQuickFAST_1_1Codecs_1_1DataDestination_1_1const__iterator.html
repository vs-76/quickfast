Detailed Description

Support for asio gather writes: forward iterator through buffers.

The intent is for DataDestination to conform to the asio::ConstBufferSequence concept. This would allow it to be passed directly to the asio::write(v) Note the implication that if asynch writes are used the DataDestination must remain intact until the write completes.
