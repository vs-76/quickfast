Applications should subscribe to the appropriate events to receive callbacks from QuickFAST

event ErrorHandler QuickFAST::DotNet::DNMessageDeliverer::CommunicationError

the event to signal communications errors.

Usage: myMessageBuilder.CommunicationError += new DNMessageDeliverer.ErrorHandler(myErrorHandler); myErrorHandler will be called with a String describing the problem. In most cases decoding will continue with the next message after the one causeing the error.
