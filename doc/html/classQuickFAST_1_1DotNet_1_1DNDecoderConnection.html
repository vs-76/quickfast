◆ joinThreads()

void QuickFAST::DotNet::DNDecoderConnection::joinThreads ( )

Wait for the decoder to come to a stop.

Unless stop() is called first (or later in another thread), this will never return. Should only be called after calling run with useThisThread = false;

◆ run() [1/2]

void QuickFAST::DotNet::DNDecoderConnection::run ( DNMessageBuilder ^ dnBuilder,
array< unsigned char >^ memoryBuffer,
long byteOffset,
long bytesUsed,
bool reset )

Run the decoder to read bytes from a buffer.

May be called repeatedly. Should be called instead of the run() method with thread counts. i.e. do not call both run() methods.

Parameters
dnBuilderis the Message Builder that receives the decoded information
memoryBuffercontains the data to be decoded
byteOffsetis the starting position in the buffer
bytesUsedis the number of bytes to be decoded
resetresets the decoder before decoding begins.

void QuickFAST::DotNet::DNDecoderConnection::run ( DNMessageBuilder ^ dnBuilder,
size_t extraThreadCount,
bool useThisThread )

Run the decoder's event loop.

Parameters
dnBuilderis the Message Builder that receives the decoded information
extraThreadCountdetermines how many additional threads will be started to support decoding'
useThisThreadTrue: control will not return to the caller until the decoding stops. False: return immediately (only makes sense if extraThreadCount > 0)

◆ stop()

void QuickFAST::DotNet::DNDecoderConnection::stop ( )

Request stop after calling run with thread counts.

Returns immediately. Call join to wait for the stop to complete.
