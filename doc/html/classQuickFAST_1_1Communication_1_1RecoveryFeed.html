Detailed Description

An abstract base class for a source of packets used to recover during arbitrage.

A derived class is responsible for seeding the free pool: call releaseBuffer() for each buffer the feed owns before the producer thread starts. A feed that never seeds the pool will park in waitFreeBuffer() until stop() is called, and getFreeBuffer() will return 0 forever.
