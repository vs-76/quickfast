In the XML template file this field is described as <int8>

◆ displayString()

virtual const StringBuffer & QuickFAST::Messages::Field::displayString ( ) const
inlinevirtualinherited

display the value as a string. Low performance

Safe to call concurrently on a shared field, which matters because fields travel as FieldCPtr – shared_ptr<const Field> – and that conventionally means shareable. The cache fill mutates a mutable StringBuffer from a const method, so two threads formatting the same decoded field used to race on its pointer, size and capacity.

References displayStringMutex(), isString(), string_, stringCached_, valid_, and valueToStringBuffer().
