Detailed Description

Multicast the contents of a FAST encoded data file.

This program uses an echo file produced by the InterpretFAST program to identify the message boundaries in a FAST encoded data file. It multicasts each message in a separate datagram.

Use the -? command line option for more information.

This program is not really FAST-aware. It is just part of a testing framework for other programs.
