Detailed Description

template<typename DATATYPE>
class QuickFAST::Messages::SingleValueBuilder< DATATYPE >

a MessageBuilder that creates a "record" containing a single value

Or more accurately, captures a single value produced by the decoder.

virtual void QuickFAST::Messages::ValueMessageBuilder::reportGap ( sequence_t startGap,
sequence_t endGap )
inlinevirtualinherited

Notify builder that packets are missing.

Called when packet sequence numbers are being used for arbitrage. No action is required. This is for information only. The method will be called after decoding the startGap-1th packet and before decoding the endGap'th packet.

New method added to the interface. It's not pure virtual to avoid breaking existing implementations.

Parameters
startGapthe sequence number of the first missing packet
endGapthe sequence number of the first packet present after the gap.
